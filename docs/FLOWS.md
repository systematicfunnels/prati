# FLOWS

## Primary User Flow
Given a first-time enterprise visitor
When they land on the homepage
Then they should understand the problem, the platform model, and the pilot CTA within one scroll sequence.

## CTA Flow
Given a buyer is interested
When they reach the contact section
Then they can start a pilot request through direct email CTA.

## Failure and Recovery
- Missing imagery: fallback alt text and intact card-based content
- Small screens: stacked layout and simplified navigation
- Reduced motion preference: transitions remain subtle and non-blocking
