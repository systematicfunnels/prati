# DESIGN SYSTEM

## Visual Direction
- Dark technical canvas with cyan accent and restrained warm highlight
- Illustration-led sections with minimal supporting copy
- Large display typography and compact enterprise navigation

## Tokens
- Color: page background, base surface, soft surface, strong surface, accent, warm accent, text tiers, border tiers
- Spacing: section shell padding and section vertical rhythm
- Radius: card and panel radii
- Motion: short hover transitions only

## Components
- Buttons use shared primary and secondary styles
- Visual cards use one reusable frame treatment
- Panels use one shared elevated surface treatment
